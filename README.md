# Airbnb Experiences Marketplace Clone

A full-stack marketplace platform for booking and hosting unique local experiences, built with modern web technologies.

## 🏗️ Project Structure

- `backend/` - Node.js/Express API with TypeScript and Prisma
- `frontend/` - React SPA (to be built by Michael)
- `shared/` - Shared TypeScript types and interfaces

## 👥 Team

## 🚀 Quick Start

### Backend Setup

```bash
cd backend
npm install
cp .env.example .env
docker-compose up -d
npm run prisma:migrate
npm run prisma:seed
npm run dev
```

See [backend/README.md](backend/README.md) for detailed instructions.
